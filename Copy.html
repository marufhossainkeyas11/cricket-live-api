Worker Source Fetcher

Cloudflare API দিয়ে deployed worker এর raw code সরাসরি টেনে আনে — dashboard editor বাদ দিয়ে।

API Token কীভাবে বানাবো?

Cloudflare dashboard → উপরে ডানদিকে প্রোফাইল আইকন → My Profile → API Tokens → Create Token → "Edit Cloudflare Workers" টেমপ্লেট বেছে নাও → Account permission এ তোমার account সিলেক্ট করে → Continue → Create Token। তৈরি হওয়া টোকেনটা এখানে বসাও (Email এর দরকার নেই এই ক্ষেত্রে)।

বিকল্প হিসেবে Global API Key ব্যবহার করলে (My Profile → API Tokens → Global API Key → View) সাথে তোমার Cloudflare login email ও দিতে হবে।
